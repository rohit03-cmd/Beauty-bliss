# Beauty Bliss - Online Cosmetic & Beauty Shop

Beauty Bliss is a web-based e-commerce platform designed for consumers to explore and purchase a wide variety of cosmetic items and luxury beauty products. The application provides a seamless shopping experience with a focus on ease of navigation and a visually appealing interface.

## 🚀 Features

- **Dynamic Product Display**: Shows "New Arrivals" and "Featured Combos" fetched directly from the database.
- **Product Search**: A dedicated search modal for finding specific beauty items quickly.
- **Interactive Banners**: A responsive hero carousel highlighting current promotions and banners.
- **Categorized Shopping**: Browse products by specific categories such as Fragrance, Health Supplements, and Baby Care.
- **Brand Showcase**: A sliding carousel displaying various beauty brands supported by the shop.
- **Customer Testimonials**: A dedicated section for user reviews and feedback to build trust.
- **Responsive Design**: Built with Bootstrap to ensure the site looks great on desktops, tablets, and mobile devices.

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript, Bootstrap
- **Backend:** PHP
- **Database:** SQL (MySQL)
- **Fonts & Icons:** Google Fonts (Roboto), FontAwesome

## 📂 Project Structure

- `/admin`: Contains administrative files for product management (e.g., image uploads).
- `/assets`: Includes CSS, JavaScript, and general theme images.
- `/brand`: Stores brand-specific logos and images.
- `/db`: Contains the `database.php` file for MySQL connection strings.
- `header.php` / `footer.php`: Global components for consistent site navigation.
